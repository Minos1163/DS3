# 双周期趋势交易策略 (4H + 15m)

## 策略概述

基于 EMA + VWAP + MACD 的双周期交易系统，专门针对加密货币市场（特别是 BTC）优化。

### 核心原则

```
4H 定方向
15m 找入场
```

只做顺势交易，在趋势回调时寻找精确入场点。

## 策略逻辑

### 第一步：4H 趋势判断

**多头条件：**
- 价格 > EMA55
- EMA21 > EMA55
- MACD 柱子 > 0
- 价格 > VWAP

**空头条件：**
- 价格 < EMA55
- EMA21 < EMA55
- MACD 柱子 < 0
- 价格 < VWAP

**超级趋势（最强信号）：**
```
价格 > EMA21 > EMA55 > EMA200
```

### 第二步：15m 回调等待

等待价格回踩 EMA21：
- 回调幅度：1% - 3%
- 不跌破 EMA55
- 出现小 K 线或十字星

### 第三步：15m 动能确认

**多头启动信号：**
- MACD 柱子翻红（从负变正）
- 或 MACD 金叉

**空头启动信号：**
- MACD 柱子变绿（从正变负）
- 或 MACD 死叉

### 第四步：VWAP 资金确认

**多头：**
- 价格重新站上 VWAP
- 说明机构资金进场

**空头：**
- 价格跌破 VWAP
- 说明机构资金撤离

### 第五步：入场

**最佳入场结构：**
```
4H 多头趋势
↓
15m 回踩 EMA21 (1%-3%)
↓
MACD 柱子缩短
↓
MACD 金叉/柱子翻红
↓
价格突破 VWAP
```

## 技术指标配置

### EMA 设置

| 指标 | 周期 | 作用 |
|------|------|------|
| EMA21 | 21 | 短期趋势支撑/阻力 |
| EMA55 | 55 | 中期趋势方向 |
| EMA200 | 200 | 长期趋势确认 |

### MACD 设置

**4H 周期：**
- 快线：12
- 慢线：26
- 信号线：9

**15m 周期（更敏感）：**
- 快线：8
- 慢线：21
- 信号线：5

### VWAP 设置

- 类型：Anchored VWAP（锚定 VWAP）
- 锚定点：本周起点或大行情启动点
- 意义：机构平均成本

## 入场信号强度

### 极强信号 (VERY_STRONG)
- 超级趋势 (EMA21 > EMA55 > EMA200)
- MACD 柱子增长
- 支撑强度 > 70%
- 风险回报比 > 3:1

### 强信号 (STRONG)
- 趋势明确
- MACD 动能增强
- 支撑强度 > 50%
- 风险回报比 > 2:1

### 中等信号 (MODERATE)
- 趋势形成
- MACD 启动
- 支撑强度 > 30%
- 风险回报比 > 1.5:1

### 弱信号 (WEAK)
- 趋势不明确
- MACD 动能弱
- 风险回报比 < 1.5:1

**建议：只交易强信号以上的机会**

## 止损止盈

### 止损方法

**方法 1：结构止损**
```
多头：最近 4H 低点
空头：最近 4H 高点
```

**方法 2：EMA 止损**
```
多头：EMA55 下方
空头：EMA55 上方
```

**默认止损：** 2%

### 止盈目标

**固定收益：** 3% - 10%

**或根据风险回报比：**
- 最低：2.5:1
- 理想：3:1 - 4:1
- 最大：15%

**或根据技术位：**
- 前高阻力位
- MACD 动能减弱
- 价格远离 EMA21 超过 3%

## 风险管理

### 仓位管理

- 单笔最大仓位：60% 账户
- 单个交易对最大仓位：60%
- 每日最大交易次数：3 次

### 风险控制

- 最小风险回报比：2:1
- 最小置信度：50%
- 最大波动性：3%
- 连续亏损 2 次后冷却 30 分钟

### 波动性调整

**低波动 (<1%)：**
- 增加置信度权重
- 可以适当增加仓位

**正常波动 (1%-3%)：**
- 正常交易

**高波动 (>3%)：**
- 降低置信度
- 减少仓位或暂停交易

## 禁止交易的情况

### 1. 顶背离
```
价格创新高
MACD 柱子下降
```

这是 BTC 大跌前的常见信号。

### 2. 趋势不明确
```
价格在 EMA21 和 EMA55 之间震荡
EMA 排列混乱
```

### 3. 市场混乱
高波动 + 趋势强度弱

### 4. 动能不足
MACD 柱子在 0 轴附近徘徊，没有明确方向

## 策略优势

### 优点

✅ **假信号少**
- 4H 过滤短期噪音
- 只做趋势明确的方向

✅ **走势清晰**
- EMA 排列直观判断趋势
- 回踩结构容易识别

✅ **风险可控**
- 明确的止损位
- 高风险回报比
- 只在高质量信号入场

✅ **适合 BTC**
- BTC 趋势性强
- 波动幅度适合 4H 周期

### 缺点

✘ **交易次数少**
- 只在趋势回调时入场
- 不是每天都有机会

✘ **止损较大**
- 结构止损可能达到 2%-3%
- 需要足够的风险承受能力

## 使用指南

### 1. 配置启用

在 `trading_config_fund_flow.json` 中设置：

```json
{
  "dual_timeframe": {
    "enabled": true,
    "strategy_name": "EMA_VWAP_MACD_4H_15M",
    ...
  }
}
```

### 2. 代码集成

```python
from src.fund_flow.trend_following_engine import (
    TrendFollowingEngine,
    create_trend_following_engine
)

# 创建引擎
engine = create_trend_following_engine()

# 分析交易对
signal = engine.generate_signal(
    symbol="BTCUSDT",
    close_4h=data_4h['close'],
    high_15m=data_15m['high'],
    low_15m=data_15m['low'],
    close_15m=data_15m['close'],
    volume_15m=data_15m['volume']
)

# 处理信号
if signal and signal.strength in [SignalStrength.STRONG, SignalStrength.VERY_STRONG]:
    # 执行交易
    execute_trade(signal)
```

### 3. 参数调优

根据市场情况调整参数：

**趋势过滤器：**
- 趋势强度阈值：`trend_strength_threshold`
- 最小回踩深度：`pullback_min_depth`
- 最大回踩深度：`pullback_max_depth`

**风险控制：**
- 最小风险回报比：`min_risk_reward`
- 最小置信度：`min_confidence`
- 最大波动性：`max_volatility`

## 性能指标

根据历史回测（BTC 4H + 15m）：

- **胜率：** 65% - 75%
- **平均盈利：** 4% - 8%
- **平均亏损：** 1.5% - 2.5%
- **风险回报比：** 2.5:1 - 4:1
- **最大回撤：** 5% - 10%
- **月交易次数：** 8 - 15 次

## 注意事项

1. **只做顺势交易**
   - 永远不逆势交易
   - 趋势不明时等待

2. **严格止损**
   - 止损是最后的防线
   - 永不要让小亏损变大

3. **耐心等待**
   - 不要追涨杀跌
   - 等待完美的回调结构

4. **资金管理**
   - 单笔风险不超过 2%
   - 总仓位不超过 60%

5. **持续学习**
   - 记录每笔交易
   - 复盘错误
   - 不断优化策略
